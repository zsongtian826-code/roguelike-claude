# ともしび迷宮 / Lantern Depths

ランタンひとつで全3階層のダンジョンを攻略する、ブラウザで遊べる2Dターン制ローグライクです。
(Vite + React + TypeScript + CSS。外部API・外部サービス・追加のゲームライブラリは使っていません。)

## 遊び方

| 操作 | 内容 |
| --- | --- |
| `W` `A` `S` `D` / 矢印キー | 上・左・下・右へ1マス移動(1ターン) |
| 画面の方向ボタン / 盤面のスワイプ | スマホ用の操作 |
| 敵のいるマスへ移動 | その敵を攻撃(威力5、1ターン) |

- 壁にぶつかる操作と、敵が残っている間の階段への移動は、ターンを消費しません。
- ポーションのマスに入ると自動で HP が 8 回復します(最大 HP まで。移動と同時で追加ターンなし)。
- 敵を全滅させると階段が開きます。第3階層の階段でクリアです。HP は階層をまたいで引き継がれます。
- タイトル画面で**シード**(0〜4294967295 の整数)を指定すると、同じダンジョンで遊べます。空欄ならランダムです。

## ルール(固定)

| | HP | 攻撃力 |
| --- | --- | --- |
| プレイヤー(灯守) | 30 | 5 |
| ぬめり(敵A) | 8 | 2 |
| 牙の番人(敵B) | 12 | 3 |

階層ごとの敵: 第1階層 A×2 / 第2階層 A×1・B×1 / 第3階層 B×2。ダメージに乱数・クリティカル・防御はありません。

敵のAI: プレイヤーのターンのあと、**ID昇順**に1体1回ずつ行動します。上下左右に隣接していれば攻撃、そうでなければ壁と他の敵を避けた最短経路で1マス近づきます(同じ長さなら 上→右→下→左 の順)。道がなければ待機します。

## 構成

```
src/
  game/          React に依存しないゲームロジック(すべて単体テスト対象)
    rng.ts         シード付き乱数(mulberry32)。Math.random は使わない
    mapGen.ts      マップ生成(11×11、到達可能性の検証、再生成の上限、フォールバック)
    pathfinding.ts 幅優先探索
    ai.ts          敵1体の行動決定
    engine.ts      1回の操作を処理する純粋関数 applyAction(state, dir)
    session.ts     入力ロック・結果保存を担当する入れ物(UIから使う)
    records.ts     localStorage に保存する記録
    score.ts       スコア計算
  ui/            React コンポーネント(盤面・HUD・画面・演出)
  audio/         WebAudio による効果音(音声ファイルなし)
  styles/        CSS
```

### 状態管理

- ゲーム状態は `GameState`(不変データ)で、`applyAction(state, dir)` が **新しい状態と起きたこと(イベント)** を返す純粋関数です。入力された状態は書き換えません。
- `GameSession` が現在の状態・入力ロック(連打防止)・終了時の記録保存を持ち、React には `useSyncExternalStore` でつなぎます。
- アニメーション・ダメージ表示・ログ・効果音は、イベントを**読むだけ**の `useFx` が担当します。演出が遅れても状態は壊れません。
- キーの長押し(リピート)は無視し、1回の有効操作のあと 120ms(階層移動の演出中は約1.1秒)は新しい操作を受け付けません。

### マップ生成

1. 外周を壁にし、内側にランダムな壁を 10〜18 個置く。
2. すべての床が1つにつながっているか、プレイヤーから BFS で検証する。
3. プレイヤー・階段(6歩以上先)・敵(4歩以上先)・ポーションを重ならないように置く。
4. 条件を満たさなければ作り直す(上限 60 回)。
5. 上限に達したら、柱が並ぶだけの開けたマップ(構造上かならず全マスがつながる)に配置するフォールバックを使う。

階層ごとに `deriveSeed(seed, floor)` で別の乱数列を作るので、同じシードなら全階層が同じ構成になります。

### 仕様の補足(仕様に明記のなかった点の判断)

- 階段のマスへの移動は成功した移動として 1 ターン・1 移動に数えます(最終階層でクリアしたときも同様)。
- 敵は階段・ポーションのマスにも立てます(アイテムは取りません)。
- 再挑戦は、シードを自分で指定していれば同じシード、していなければ新しいランダムシードで始まります。
- 記録は「クリア時の最小ターン数」「最高スコア」「直近5回の結果(クリア・敗北とも)」を保存します。
- スコア = 3000 + 残りHP×50 + max(0, 1500 − ターン×10) + 倒した敵×100 − 受けたダメージ×10(下限0)。クリア時のみ。
